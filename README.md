# Medical Data History – SQL Data Analysis Capstone

## Project Overview
This project focuses on analyzing a medical database using SQL to extract meaningful insights about patients, admissions, doctors, diagnoses, and medical records.

The project was completed as part of the DataMites Data Analytics Capstone.

## Project Objectives
- Retrieve and analyze patient information.
- Examine patient demographics and gender distribution.
- Analyze hospital admissions and discharge records.
- Explore diagnoses and doctor information.
- Identify missing values and data quality issues.
- Use SQL joins, aggregate functions, filtering, sorting, and subqueries.

## Tools and Technologies
- MySQL Workbench
- SQL
- Microsoft Excel
- Microsoft Word
- Microsoft PowerPoint

## Database Tables
- Patients
- Admissions
- Doctors
- Province Names
- Patients and admissions diagnosis records

## Key Findings
- Total patients: 4,530
- Male patients: 2,468 (54.5%)
- Female patients: 2,062 (45.5%)
- Total admissions: 5,067
- Patients with missing allergy information: 2,059
- Same-day admissions and discharges: 481

## Data Quality Limitation
An UPDATE statement intended to replace NULL allergy values with 'NKA' was attempted but could not be executed because the database account did not have UPDATE permission. The original data was preserved.

## Project Deliverables
- SQL query script
- Excel file containing query results
- Key insights document
- SQL execution screenshots
- Project report
- PowerPoint presentation

## Conclusion
This project demonstrates the use of SQL for querying, joining, filtering, grouping, and analyzing healthcare data. The analysis provides insights into patient demographics, hospital admissions, diagnoses, and data quality limitations.
